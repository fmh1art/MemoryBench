3. Video quality metrics currently ENABLED in daily evaluation

Pixel/reference fit:
  mse, mae                         lower is better
  psnr_db                         higher; -10 log10(clip MSE), not mean frame PSNR
  ssim                            higher; 11x11 Gaussian, sigma 1.5, RGB mean
  ms_ssim                         higher; five fixed scales

Temporal/reference fit:
  temporal_difference_l1           lower; L1 of Gen vs GT signed frame differences

Last aligned frame:
  final_mse                       lower
  final_ssim                      higher

Diagnostics WITHOUT a universal better/worse direction:
  gt_laplacian_variance,
  gen_laplacian_variance           sharpness proxies; noise also increases them
  gt_adjacent_l1, gen_adjacent_l1  change/motion proxies; static is not necessarily good

These are 12 scalar outputs, not 12 independent notions of video quality.
There is no weighted combined automatic "video quality score".

4. Implemented but NOT enabled in the captured daily run

  lpips, final_lpips: pretrained AlexNet LPIPS v0.1; lower is better.
  niqe: PyIQA NIQE of generated frames, averaged; lower is better.

The captured run has learned=[] and device=cpu. The worker does not pass
--learned. Enabling these optional metrics is a new diagnostic experiment,
not a reproduction of the current daily metric set. They require their optional
dependencies/weights and workers=1. Missing dependencies/weights fail explicitly;
there is no random-weight or substitute metric fallback. NIQE is a frame-quality
metric, not a temporal video-quality model.

CLIP similarity, FID and FVD are NOT implemented in this frozen version.

5. Sampling and aggregation contract

All pixel metrics use RGB in [0,1]. Evaluate the full shared future interval,
excluding Prefix, at 24 Hz plus the last shared timestamp, with no frame cap.
Use decoded timestamps and explicit GT/Gen start offsets, nearest-frame matching,
and maximum sampling error/inter-stream skew 0.1 seconds. Do not independently
normalize or stretch the two timelines.

Fit GT within 320x192 preserving aspect ratio, then evaluate at its content size
(4:3 gives 256x192). Fit/pad Gen to that size. Inspect shared duration separately:
a truncated output is scored on overlap, which is not proof of task completion.

Average frame scores within each case, then weight cases equally. PSNR uses
clip MSE. Exact identity PSNR is "inf"; MS-SSIM is null below 161 pixels on either
axis; temporal metrics are null for fewer than two frames. Nulls and errors do
not become zero. Automatic diagnostics include Gate-failed cases independently.

6. Memory/Gate are separate from video quality

Gate = Observability AND Action Following. Observability can reject persistent
blur/ghosting/corruption; it is not a continuous aesthetic-quality score.
Memory dimensions are Inventory (presence/count), Appearance (visual/shape,
matched objects only), and Spatial (localization/relations). Their core score
uses temporal means followed by a geometric mean, scaled to 100. Gate failures
receive zero. v3.4 missing-core-evidence policy assigns case zero while retaining
raw missing evidence; API/schema errors are failures, not valid zero scores.
Environment is optional and excluded from the core score; it is not enabled by
the default protocol. Gate uses 12 aligned frames; Memory uses 8 aligned pairs,
unlike the full-interval 24 Hz automatic metrics.

High pixel similarity or sharpness does not establish memory, physical
correctness or good action following; camera alignment/background dominate many
full-reference metrics. Keep automatic diagnostics and semantic scores separate.

7. Inventory deployment repair

ops/b300_daily/inventory_repair.py preserves the deployed bounded repair for the
specific native (gt_count, gen_count) == (0, 0) format error. It preserves the
failed reply and makes a constrained-decoding request with the same prompt,
images, model and sampling. Native validation/scoring remains authoritative.
Schema-valid zero scores are never retried to improve scores.

The ordinary `python -m evaluation.run` CLI does NOT automatically install this
deployment repair; the captured evaluation_worker.py explicitly uses make_judge.
Do not describe the native CLI alone as reproducing the deployed retry behavior.
The adapters' exact runtime/identity guards are retained, not loosened for this
checkout. Unsupported identities fail explicitly.

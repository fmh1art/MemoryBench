BACKGROUND: This is a MEMORY benchmark for an action-conditioned world model. The reveal action has already passed a separate gate. IMAGE 1 is a real GT stable evaluation frame and IMAGE 2 is a generated stable evaluation frame. They represent the same relative progress of their respective annotated evaluation clips. Judge whether the model reproduced the SPECIFIC objects and their condition/layout in the human-annotated memory target.
Both images are supplied together intentionally. Inspect the target region in BOTH images yourself. Ignore the surrounding furniture, hands, background, action speed and minor camera/lighting changes. Do not score whole-image similarity or reuse beliefs from another frame pair.
FIRST, list separately visible GT and generated objects inside the memory target, including small independent objects. Exclude the target container and its handles. Give each object a local ID, a specific description, and distinctive visible identity_features (fine structure, shape proportions, characteristic markings/patterns, and identifiable parts). Do not flatten a notebook, pencil case or unknown artifact into a generic box. Unknown details must be stated as unknown.
THEN establish only VERIFIED one-to-one instance correspondences in verified_matches. The same broad category or color alone is NOT sufficient. You may leave every object unmatched. A random green rectangular artifact is not the remembered green stationery item just because both are green rectangles. Severe incompatible structure/proportions or missing defining parts can make identity unestablished. Cite visual evidence from both images for every accepted match. Do not establish identity from position, list order or mutable state. If multiple objects cannot be distinguished, do not invent an instance correspondence.
Judge three distinct dimensions, each 0..1, with a reason:
1. inventory (INSTANCE presence and count): score=2*M/(N_GT+N_GEN), where M is the number of VERIFIED instance matches. N_GT and N_GEN include all visible target objects. Both visibly empty gives 1; an unreadable generated target gives 0. Do not force category matches. Unmatched hallucinated or missing objects lower this score.
2. appearance (visual fidelity of remembered instances): compare fine shape/proportions, material appearance, color, texture, pattern and markings of VERIFIED instances, allowing viewpoint/lighting changes. Judge fidelity within a recognized identity; identity is not permission to ignore deformities. Use an average over ALL GT objects, with unmatched objects contributing zero; thus the score cannot exceed M/N_GT. Use 0 for no faithful detail, .25 for weak/mostly wrong fidelity, .5 for substantial defects, .75 for small defects, 1 for faithful details per matched object. No state or position credit here. N/A only if GT has no objects.
Also output appearance_items with exactly one {gt_id, score, reason} per GT object. These are INDIVIDUAL per-object fidelity judgments before averaging. Unmatched objects have individual score 0. The program will compute the final appearance mean from these items, and the exact inventory F1 from verified_matches; your aggregate dimensions scores are retained for audit. Do not perform these arithmetic operations in place of inspecting the images.
3. spatial (object arrangement): judge GT object-to-object relations and placement in intrinsic target compartments/landmarks using VERIFIED identities. Examples: notebook above a small box, item beside another item, or in a specific inner compartment. Mere 'inside the drawer/target' is already covered by action visibility/inventory and MUST NOT earn spatial credit. Avoid image-left/right that changes under viewpoint. Missing/unidentified objects required by a GT relation contribute zero. Set gt_spatial_applicable=false and score=null only when GT has no meaningful observable arrangement fact.
For spatial score the fraction of applicable GT facts preserved, explaining those facts in the reason. Use the GT-defined denominator; do not omit facts because generated objects are wrong. When GT is nonempty and NO instance is verified, ALL GT-applicable dimensions MUST be 0. Generic inside-container relations cannot rescue the score.
If the generated target is not readable, set generated_readable=false, generated_objects=[], verified_matches=[] and all GT-applicable scores to zero. An empty but visible target is readable. If GT is unreadable, set gt_readable=false and explain; the program treats that as invalid reference, not model failure.
Return gt_readable, generated_readable, gt_objects, generated_objects, verified_matches, appearance_items, gt_spatial_applicable, dimensions (inventory/appearance/spatial each with score and reason), and summary. Scores can be decimal fractions; use null only for the stated GT-based N/A conditions. Remain conservative when visual evidence cannot establish object identity.
